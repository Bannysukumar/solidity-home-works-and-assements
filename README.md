## Overview

Solidity Home Works And Assements ships AggregatorV3Interface.sol, OwnableUpgradeable.sol, VotesUpgradeable.sol, Initializable.sol, ERC20Upgradeable.sol, ERC20BurnableUpgradeable.sol, ERC20PermitUpgradeable.sol, ERC20VotesUpgradeable.sol, ContextUpgradeable.sol, NoncesUpgradeable.sol, EIP712Upgradeable.sol, Ownable.sol, IVotes.sol, IERC5267.sol, IERC5805.sol, IERC6372.sol, draft-IERC6093.sol, ERC20.sol, IERC20.sol, ERC20Burnable.sol, ERC20Permit.sol, IERC20Metadata.sol, IERC20Permit.sol, Context.sol, Nonces.sol, Panic.sol, ShortStrings.sol, StorageSlot.sol, Strings.sol, ECDSA.sol, EIP712.sol, MessageHashUtils.sol, Math.sol, SafeCast.sol, SignedMath.sol, Checkpoints.sol, Time.sol, remix_accounts.sol, remix_tests.sol, 1_Storage.sol alongside the frontend in this repository.


What is actually in the repository: `.deps/npm/@chainlink/contracts/src/v0.8/interfaces/AggregatorV3Interface.sol`, `.deps/npm/@openzeppelin/contracts-upgradeable/access/OwnableUpgradeable.sol`, `.deps/npm/@openzeppelin/contracts-upgradeable/governance/utils/VotesUpgradeable.sol`, `.deps/npm/@openzeppelin/contracts-upgradeable/proxy/utils/Initializable.sol`, `.deps/`, `.states/`, `contracts/`, `scripts/`, `tests/`. GitHub reports the primary language as Solidity.

## Features


- AggregatorV3Interface contract with decimals, description, version, getRoundData
- OwnableUpgradeable contract with _getOwnableStorage

- Initializable Solidity contract
